Currently, every sunday I need to make a powerpoint presentation for mass that can be projected to show hymns, prayers, etc. I would like to automate this using a template and a python script. I would like to be able to input a CSV file with what we are playing for the week and have the script generate a new powerpoint presentation based on that. There is an example in the folder called mass_setup.csv. All of the hymns will supplied in markdown format, which are all in the assets folder. All of the prayers are already in the template. The structure of the template is layed out in the ppt_structure.md file. The template itself is called mass_of_renew_template.pptx.

Some things to note though is that in the template, There are 3 offertory hymns and 2 communion hymns, which might not always be the case. There may be week where there are only 2 offertory hymns, 1 communion, etc., so the script should be able to remove sections referencing the ppt structure. The divider slides are the slides with nothing on them except a slide background. There will never be 2 divider slides next to each other in the final presentation. When run I would like the antigravity CLI to look up the readings online for this week in the catholic faith and generate a 4:3 image based on the theme for the week and change all of these divider slides to use this image as the background. Also, slide 1 in the template is the title slide. I would like the antigravity CLI to check which week it is in the catholic church and replace the text, for example "27th Sunday in Ordinary Time". Then the response slide also need to be updated with whatever the correct response if for the week according to the psalm, which the antigravity CLI will need to fetch as well.

In the mass_setup.csv file, ignore the mass;mass_of_renew section because that is already in the template.
